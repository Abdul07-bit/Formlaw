## Workflow: CONTRACT_REVIEW
Identify, only where the clause exists in the document:
- parties, effective date, term, renewal, termination and notice periods
- payment terms and key obligations
- liability, indemnity, confidentiality, intellectual property, data protection
- governing law, jurisdiction, dispute resolution, non-compete, non-solicitation
- unusual or one-sided clauses, and ambiguous language
- potential risks (with evidence), each with a recommended action where useful
Never invent a clause. If a standard provision (for example governing law, liability cap,
indemnity) is not present, report it under missing_information rather than describing it.
Use the contract's own section labels for the `section` field when they appear in the text.
